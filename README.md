# Ed — 3D Product Imaging (portfolio site)

Single-page portfolio with GSAP animations. No build step.

## Publish on GitHub Pages
1. Create a public repo named `yourusername.github.io`.
2. Upload every file in this folder (including `.nojekyll`) to the repo root.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Site goes live at `https://yourusername.github.io` in 1–2 minutes.

## Before sharing
- Replace the four "Render slot" tiles with your real renders.
- Replace the "add your email" placeholder in the Contact section.
- Check package prices.
